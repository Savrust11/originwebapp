## 修正11：クイックログに体温記録を追加

### 要望
「クイックログに体温を記載するところが欲しい」

### 背景
毎朝の検温は保育園の連絡帳に記入が必要。赤ちゃんの発熱はすぐに記録したい。現在のWe育には体温を記録する場所がない。

### 修正内容
クイックログに「たいおん」ボタンを追加する。ただし全ユーザーに表示するのではなく、設定で表示/非表示を選択できるようにする。

**ボタン仕様：**
- ラベル: たいおん
- アイコン: 🌡️（体温計）
- カテゴリ: タイムライン（何時に何度だったかが重要）
- 色: 既存のボタンに合わせた淡い色（赤系を推奨）

**設定画面での表示切替：**
設定画面に「クイックログのカスタマイズ」セクションを追加。
各ボタンの表示/非表示をトグルスイッチで切り替えられるようにする。

```
クイックログのカスタマイズ
─────────────────
ミルク　　　　　[ON]
おむつ　　　　　[ON]
ねんね　　　　　[ON]
はじめて　　　　[ON]
おふろ　　　　　[ON]
あそび　　　　　[ON]
はみがき　　　　[ON]
おくすり　　　　[ON]
たいおん　　　　[OFF] ← デフォルトOFF
ありがとう　　　[ON]  ← 常にON、非表示不可
```

- たいおんはデフォルトOFF（必要な人だけONにする）
- ありがとうはWe育のコア機能なので非表示不可
- 他のボタンは自由にON/OFF可能

**記録内容：**
- 日時（デフォルト: 現在時刻、変更可能）
- 体温（数値入力：小数点1桁、例「36.8」「37.5」）
  - 入力UIはスクロール式の数値ピッカー推奨（35.0〜42.0の範囲）
  - デフォルト値: 36.5
- 担当（ママ/パパ — 自動で記録者の役割が入る）
- メモ（任意：「鼻水あり」「元気」等）

**体温に応じた色分け表示：**
タイムラインに表示する際、体温に応じて色を変える。

| 体温 | 色 | 意味 |
|---|---|---|
| 〜37.4℃ | 🟢 グリーン | 平熱 |
| 37.5〜37.9℃ | 🟡 イエロー | 微熱 |
| 38.0℃〜 | 🔴 レッド | 発熱 |

**フェーズ別表示：**
設定でONにすれば全フェーズで表示可能。

**クイックログのボタン配置（たいおんON時）：**
```
ミルク     おむつ     ねんね
はじめて    おふろ     あそび
はみがき    おくすり    たいおん
ありがとう
```

### データ保存
- ログ種別: 'temperature'
- 既存のactivity_logsテーブルに type='temperature' として保存
- 追加カラム:
  - `temperature`: DECIMAL(3,1)（体温値、例: 36.8）
- ポイント付与: 他の育児行為と同じくポイント加算対象

### テスト項目
- [ ] 設定画面に「クイックログのカスタマイズ」セクションが表示される
- [ ] たいおんをONに切り替え → クイックログにたいおんボタンが表示される
- [ ] たいおんボタンをタップ → 体温入力画面が表示される（デフォルト36.5）
- [ ] 体温38.2を入力して保存 → タイムラインに🔴赤色で表示される
- [ ] 体温36.5を入力して保存 → タイムラインに🟢緑色で表示される
- [ ] たいおんをOFFに切り替え → クイックログからたいおんボタンが消える
- [ ] ありがとうボタンはOFF切替不可
- [ ] 記録するとポイントが加算される

## 修正12：ボトムナビゲーションに「タイムライン」を追加（5タブ構成）

### 要望
「下のアイコンに、24時間タイムラインを入れて欲しい」

### 背景
24時間タイムラインはWe育で最も頻繁に使う機能の1つ。現在はホーム画面をスクロールしないとアクセスできない。どの画面からでもワンタップでタイムラインに移動したい。

### 修正内容
ボトムナビゲーションを4タブから5タブに変更する。

**変更前（4タブ）：**
```
🏠 ホーム　　📅 カレンダー　　🎁 ご褒美　　⚙️ 設定
```

**変更後（5タブ）：**
```
🏠 ホーム　　🕐 タイムライン　　🎁 ご褒美　　📅 カレンダー　　⚙️ 設定
```

**各タブの役割：**

| タブ | アイコン | 機能 | 使う場面 |
|---|---|---|---|
| ホーム | 🏠 | クイックログ、TODAY'S SUMMARY、WAKE WINDOW等 | 記録する時 |
| タイムライン | 🕐 | 24時間タイムラインの全画面表示 | 「さっき何時にミルクあげた？」 |
| ご褒美 | 🎁 | ご褒美ショップ、ポイント確認 | ポイントを使う時 |
| カレンダー | 📅 | 月間カレンダー、ことば・はじめて等の日付記録 | 「来週の予防接種いつ？」 |
| 設定 | ⚙️ | プロフィール、子ども情報、クイックログカスタマイズ | 設定変更時 |

**デザイン仕様：**
- 5タブは一般的なアプリ構成で問題なし（Instagram、LINE等も5タブ）
- タブ幅は均等配分（画面幅 ÷ 5）
- アクティブタブはアイコンとラベルの色をアプリのテーマカラー（紫系）に
- 非アクティブタブはグレー

**タイムライン全画面表示の内容：**
- 24時間タイムラインをフルスクリーンで表示
- 日付の前後移動ボタン（< 昨日 | 今日 | 明日 >）
- ログの編集・削除は既存のタイムラインと同じ操作

**注意：**
- ホーム画面にも引き続きタイムラインのカード（サマリー版）は残す
- ボトムナビのタイムラインは全画面の詳細版
- ご褒美タブの位置を中央に配置（目立つ位置でWe育の特徴をアピール）

### テスト項目
- [ ] ボトムナビに5つのタブが表示される
- [ ] タイムラインタブをタップ → 24時間タイムラインが全画面表示される
- [ ] 日付の前後移動ができる
- [ ] ホーム画面のタイムラインカードも引き続き表示される
- [ ] ご褒美タブが中央に配置されている
- [ ] 全タブの遷移が正常に動作する
- [ ] アクティブタブのハイライト表示が正しい
