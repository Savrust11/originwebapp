## 修正5：おむつログに便の種類選択（量・形状）を追加

### 問題
便秘の子どもを持つ親から「便の量や種類が選択できると助かる」という要望。現在のおむつログは「おしっこ / うんち / 両方」の選択のみで、便の詳細を記録できない。

### 修正内容
おむつログで「うんち」または「両方」を選択した場合、追加の選択項目を表示する。

**UIの追加フィールド：**

#### 便の形状（ブリストルスケールを参考に、育児向けに簡略化）
6つの選択肢をアイコン付きで横並びに表示する：

| 選択肢 | アイコン | 説明 | 対応するブリストルスケール |
|---|---|---|---|
| コロコロ | 🟤（小さい丸） | 硬くてコロコロした便 | Type 1-2（便秘気味） |
| かため | 🟫（太い棒） | 形はあるが硬い | Type 3 |
| ふつう | 🍌（バナナ型） | バナナ状のなめらかな便 | Type 4（理想的） |
| やわらかめ | 🟡（柔らかい塊） | 形が崩れやすい軟便 | Type 5 |
| どろどろ | 🟠（液状） | 泥状・水っぽい | Type 6 |
| みずっぽい | 💧（水滴） | ほぼ水状の下痢便 | Type 7（下痢） |

#### 便の量
3つの選択肢をアイコン付きで横並びに表示する：

| 選択肢 | 表示 |
|---|---|
| 少ない | ● |
| ふつう | ●● |
| 多い | ●●● |

#### 便の色（任意）
5つの選択肢をカラーチップで横並びに表示する：

| 選択肢 | 色 |
|---|---|
| きいろ | 🟡 |
| みどり | 🟢 |
| ちゃいろ | 🟤 |
| くろっぽい | ⚫ |
| しろっぽい | ⚪ |

### UIの挙動
1. おむつボタンをタップ
2. 「おしっこ / うんち / 両方」を選択
3. 「うんち」または「両方」を選んだ場合のみ、追加の選択項目が展開表示される
4. 形状は必須、量と色は任意（デフォルト「ふつう」）
5. 記録保存後、タイムラインには形状アイコンも表示する

### データ保存
既存のおむつログのテーブルに以下のカラムを追加：
- `stool_type`: TEXT（'hard_lumps' / 'hard' / 'normal' / 'soft' / 'mushy' / 'watery'）、NULL許可
- `stool_amount`: TEXT（'small' / 'normal' / 'large'）、NULL許可
- `stool_color`: TEXT（'yellow' / 'green' / 'brown' / 'dark' / 'white'）、NULL許可

### テスト項目
- [ ] おむつで「うんち」を選択 → 形状・量・色の選択項目が表示される
- [ ] おむつで「おしっこ」を選択 → 追加項目は表示されない
- [ ] 形状「コロコロ」量「少ない」色「きいろ」を選択して保存 → タイムラインに反映
- [ ] 量と色を選択せずに保存 → デフォルト値で保存される
- [ ] 保存したログを編集 → 便の詳細も編集できる

## 修正6：クイックログに「歯磨き」ボタンを追加

### 問題
モニターから「歯磨き🪥」をクイックログに追加してほしいという要望。歯磨きは毎日の習慣であり、記録することでしつけの達成感やパートナーとの分担に繋がる。

### 修正内容
クイックログに「はみがき」ボタンを追加する。

**ボタン仕様：**
- ラベル: はみがき
- アイコン: 🪥（歯ブラシ）または歯のアイコン
- カテゴリ: タイムライン（時刻が重要：朝・昼・夜の記録）
- 色: 既存のボタンに合わせた淡い色（水色系を推奨）

**フェーズ別表示：**

| フェーズ | 表示 | 理由 |
|---|---|---|
| 新生児(0-5m) | — | 歯がまだ生えていない |
| 乳児(6-11m) | ✅ | 歯が生え始める時期。歯磨き習慣の開始 |
| 1歳(12-23m) | ✅ | 歯磨き習慣の定着期 |
| 幼児(2-3歳) | ✅ | 仕上げ磨きが重要 |
| 園児(4-6歳) | ✅ | 自分で磨く練習 |

**記録内容：**
- 日時（デフォルト: 現在時刻、変更可能）
- 担当（ママ/パパ — 自動で記録者の役割が入る）
- メモ（任意：「嫌がらずにできた」「上の歯だけ」等）

**クイックログのボタン配置（修正後）：**
```
ミルク    おむつ    ねんね
はじめて   おふろ    あそび
はみがき   ありがとう
```

### データ保存
- ログ種別: 'toothbrush'
- 既存のactivity_logsテーブルに type='toothbrush' として保存
- ポイント付与: 他の育児行為と同じくポイント加算対象

### テスト項目
- [ ] 生後6ヶ月以上の子どもでクイックログを開く → 「はみがき」ボタンが表示される
- [ ] 生後5ヶ月以下の子どもでは「はみがき」ボタンは表示されない
- [ ] はみがきボタンをタップ → 記録される → タイムラインに歯ブラシアイコンで表示
- [ ] 記録するとポイントが加算される
- [ ] 24時間タイムラインにも正しく表示される

## 修正7：タイムラインに「おくすり」ボタンを追加

### 問題
モニターから「タイムライン画面で投薬記録ができると嬉しい」という要望。子どもの服薬（解熱剤、抗生物質、ビタミンD等）は時刻と量の正確な記録が重要。

### 修正内容
クイックログに「おくすり」ボタンを追加する。

**ボタン仕様：**
- ラベル: おくすり
- アイコン: 💊（薬）または薬のアイコン
- カテゴリ: タイムライン（何時に何を飲んだかが重要）
- 色: 既存のボタンに合わせた淡い色（ピンク系を推奨）

**フェーズ別表示：**

| フェーズ | 表示 | 理由 |
|---|---|---|
| 新生児(0-5m) | ✅ | ビタミンK等の投与あり |
| 乳児(6-11m) | ✅ | 風邪薬・解熱剤等 |
| 1歳(12-23m) | ✅ | 同上 |
| 幼児(2-3歳) | ✅ | 同上 |
| 園児(4-6歳) | ✅ | 同上 |

**記録内容：**
- 日時（デフォルト: 現在時刻、変更可能）
- 薬の名前（テキスト入力、過去に入力した薬名をサジェスト表示）
- 量（テキスト入力：例「5ml」「1包」「1錠」）
- 担当（ママ/パパ — 自動で記録者の役割が入る）
- メモ（任意：「嫌がって半分吐き出した」「食後」等）

**クイックログのボタン配置（修正6と合わせた最終版）：**
```
ミルク     おむつ     ねんね
はじめて    おふろ     あそび
はみがき    おくすり    ありがとう
```

### データ保存
- ログ種別: 'medicine'
- 既存のactivity_logsテーブルに type='medicine' として保存
- 追加カラム:
  - `medicine_name`: TEXT（薬の名前）
  - `medicine_dose`: TEXT（量）
- ポイント付与: 他の育児行為と同じくポイント加算対象

### 薬名のサジェスト機能
- 過去にそのユーザーが入力した薬名をリストとして保持
- 入力時にサジェスト（オートコンプリート）として表示
- 例：一度「カロナール」と入力すると、次回から「カ」と入力した時点で「カロナール」が候補に出る

### テスト項目
- [ ] 全フェーズの子どもでクイックログを開く → 「おくすり」ボタンが表示される
- [ ] おくすりボタンをタップ → 薬名と量の入力画面が表示される
- [ ] 薬名「カロナール」量「5ml」と入力して保存 → タイムラインに💊アイコンで表示
- [ ] 2回目の記録時、「カ」と入力 → 「カロナール」がサジェストされる
- [ ] 記録するとポイントが加算される
- [ ] 24時間タイムラインにも正しく表示される
- [ ] 保存したログを編集・削除できる
