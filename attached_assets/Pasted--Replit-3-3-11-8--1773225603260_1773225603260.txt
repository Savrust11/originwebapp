## 修正8：離乳食の「初めて食べた食材」記録機能

### 要望
「ごはんで初めて食べた食材を記録していけると助かる」

### 背景
離乳食期（生後5〜18ヶ月）は新しい食材を1つずつ試していく。アレルギー確認のためにも「いつ・何を・初めて食べたか」の記録が重要。小児科で聞かれることも多い。

### 修正内容
ごはん（離乳食）の記録画面に「初めての食材」チェック機能を追加する。

**UIの追加要素：**

#### 1. ごはん記録画面に「食材を追加」ボタン
- ごはんログの入力画面（タイムラインのごはんボタン）に「食材を記録」セクションを追加
- タップすると食材選択画面が開く

#### 2. 食材選択画面
月齢に応じた食材リストを表示。カテゴリ分けで表示する。

**カテゴリと食材例：**

| カテゴリ | 食材例 |
|---|---|
| 穀類 | おかゆ（10倍がゆ）、おかゆ（7倍がゆ）、パン、うどん、そうめん、パスタ、オートミール |
| 野菜 | にんじん、かぼちゃ、ほうれん草、小松菜、ブロッコリー、トマト、さつまいも、じゃがいも、大根、玉ねぎ、キャベツ、なす、とうもろこし、枝豆 |
| 果物 | りんご、バナナ、みかん、いちご、もも、ぶどう、メロン、すいか、梨、キウイ |
| たんぱく質（豆類） | 豆腐、納豆、きなこ、枝豆 |
| たんぱく質（魚） | しらす、たい、かれい、たら、さけ、まぐろ、ツナ（水煮） |
| たんぱく質（肉） | 鶏ささみ、鶏むね肉、鶏もも肉、豚ひき肉、牛ひき肉、レバー |
| たんぱく質（卵・乳） | 卵黄、全卵、牛乳、ヨーグルト、チーズ |
| その他 | 海苔、わかめ、ごま、だし（かつお）、だし（昆布）、しょうゆ、みそ、バター |

#### 3. 食材の状態表示
各食材に3つの状態アイコンを表示：

| 状態 | アイコン | 意味 |
|---|---|---|
| 未試行 | ○（グレー） | まだ食べたことがない |
| 食べた（問題なし） | ✅（グリーン） | 食べてアレルギー反応なし |
| 要注意 | ⚠️（オレンジ） | アレルギー反応あり・要確認 |

- 食材をタップすると状態が切り替わる
- 「✅食べた」に切り替えた時、自動で日付が記録される
- 「⚠️要注意」を選んだ場合、メモ入力欄が表示される（症状の記録用）

#### 4. 食材一覧画面
カレンダーの「ごはん」カテゴリから、食材チェックリストの一覧画面にアクセスできる。
- 食べた食材数 / 全食材数を進捗バーで表示（例：32 / 78食材）
- カテゴリごとにフィルタ可能
- 日付順（最近食べた順）でソート可能

#### 5. カスタム食材の追加
リストにない食材を自由に追加できる「＋食材を追加」ボタン

### データ保存
新規テーブル `food_ingredients`:
- `id`: PRIMARY KEY
- `family_id`: TEXT（家族ID）
- `child_id`: TEXT（子どものID）
- `ingredient_name`: TEXT（食材名）
- `category`: TEXT（カテゴリ名）
- `status`: TEXT（'not_tried' / 'ok' / 'caution'）
- `first_tried_date`: DATE（初めて食べた日付）
- `notes`: TEXT（メモ、特にアレルギー反応の記録用）
- `is_custom`: BOOLEAN（カスタム追加食材かどうか）
- `created_at`: TIMESTAMP
- `updated_at`: TIMESTAMP

### フェーズ別表示
| フェーズ | 表示 | 理由 |
|---|---|---|
| 新生児(0-4m) | — | 離乳食前 |
| 乳児(5-11m) | ✅ | 離乳食開始期 |
| 1歳(12-23m) | ✅ | 離乳食完了〜幼児食移行期 |
| 幼児(2-3歳) | ✅ | アレルギー確認で参照 |
| 園児(4-6歳) | — | 通常不要 |

### テスト項目
- [ ] ごはん記録画面に「食材を記録」セクションが表示される
- [ ] 食材リストが月齢に応じたカテゴリで表示される
- [ ] 食材をタップ → ✅に切り替わり日付が自動記録される
- [ ] ⚠️をタップ → メモ入力欄が表示される
- [ ] カスタム食材を追加できる
- [ ] 食材一覧画面で進捗バーが表示される
- [ ] パートナー間で食材データが共有される

## 修正9：パートナーの分を代理入力できる機能

### 要望
「夫が自分で入力しないので、代わりに私が夫の分を入力してあげられる機能がほしい」

### 背景
パートナーが忙しい・面倒がりで自分でログを入力しない場合、もう一方が代わりに記録したい。現在は各自のアカウントからしか入力できないため、パートナーの育児貢献が可視化されない。

### 修正内容
クイックログと全てのログ入力画面に「担当者選択」機能を追加する。

**UIの変更：**

#### 記録画面に「だれがやった？」セクションを追加
ログ入力時に、担当者を選択できるようにする。

```
だれがやった？
[ママ]  [パパ]
```

- デフォルトは現在ログイン中のユーザー（自分）が選択された状態
- パートナーのボタンをタップすると、パートナーの記録として保存される
- ボタンはパートナー登録済みの場合のみ表示
- パートナー未登録の場合はこのセクションを非表示

**適用範囲：**
全てのクイックログボタン：
- ミルク、おむつ、ねんね、ごはん、おやつ、おふろ、トイレ、はみがき、おくすり、ありがとう

全てのカレンダー入力：
- ことば、あそび、はじめて、しつけ、きょうみ、できた

**ポイント制度との連動：**
- パートナーの分を代理入力した場合、ポイントはパートナーに加算される
- 貢献度ダッシュボードにもパートナーの実績として反映される
- 「代理入力」であることはデータ上記録するが、UIには特に表示しない（パートナーが気にする可能性があるため）

### データ保存
既存のログテーブルに以下のカラムを追加：
- `recorded_by`: TEXT（実際に記録した人のユーザーID）
- `performed_by`: TEXT（実際に育児を行った人のユーザーID）

※既存のログで `recorded_by` がNULLの場合は、`performed_by` と同じ（自分で記録した）として扱う

### テスト項目
- [ ] クイックログ画面に「だれがやった？」セクションが表示される
- [ ] パートナーを選択して記録 → パートナーの実績として保存される
- [ ] 貢献度ダッシュボードにパートナーの実績が正しく反映される
- [ ] ポイントがパートナーに加算される
- [ ] パートナー未登録の場合は「だれがやった？」セクションが非表示
- [ ] デフォルトは自分が選択された状態

## 修正10：名もなき育児のカスタム項目追加機能

### 要望
「名もなき育児の現在の項目にプラスして、各家庭でカスタマイズ可能欄もあれば」

### 背景
現在の名もなき育児の項目は共通だが、家庭によって異なる育児タスクがある。例：「保湿クリーム塗る」「耳掃除」「爪切り」「体温測定」「アレルギー薬の管理」など。

### 修正内容
名もなき育児の項目リストの最後に「＋カスタム項目を追加」ボタンを設置する。

**UIの追加：**

#### 1. 既存の名もなき育児リストの末尾に追加ボタン
```
[既存項目1] [既存項目2] [既存項目3]
[既存項目4] [既存項目5] [既存項目6]
...
[＋ カスタム項目を追加]
```

#### 2. カスタム項目の追加画面
タップすると入力ダイアログが表示：
- 項目名（テキスト入力、最大20文字）
- アイコン選択（プリセットから選ぶ：⭐🏠💊🧴✂️🌡️🧹🛒📋📞）
- 「追加」ボタンで保存

#### 3. カスタム項目の管理
- 追加したカスタム項目は家族単位で共有される（ママが追加したらパパにも表示される）
- カスタム項目は設定画面から編集・削除が可能
- 最大10個まで追加可能
- カスタム項目もポイント付与の対象

#### 4. 話し合いの負担を減らす設計
- カスタム項目の追加はどちらか一方が行えばOK（承認フローは不要）
- 追加された時にパートナーに通知は出さない（自然に一覧に表示される）
- 削除の場合のみ確認ダイアログを表示

### データ保存
新規テーブル `custom_childcare_items`:
- `id`: PRIMARY KEY
- `family_id`: TEXT（家族ID）
- `item_name`: TEXT（項目名、最大20文字）
- `icon`: TEXT（アイコン文字列）
- `created_by`: TEXT（作成者のユーザーID）
- `is_active`: BOOLEAN（有効/無効）
- `created_at`: TIMESTAMP

### テスト項目
- [ ] 名もなき育児リストの末尾に「＋カスタム項目を追加」ボタンが表示される
- [ ] ボタンをタップ → 項目名とアイコン選択の入力画面が表示される
- [ ] カスタム項目を追加 → リストに表示される
- [ ] カスタム項目をタップ → 記録される → ポイントが加算される
- [ ] パートナーのアカウントでもカスタム項目が表示される
- [ ] 設定画面からカスタム項目を編集・削除できる
- [ ] 最大10個を超えると追加ボタンが非表示になる
- [ ] 貢献度ダッシュボードにカスタム項目の実績が反映される
