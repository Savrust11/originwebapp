## STEP 1: 翻訳ファイルの作成とi18nの導入

```
アプリを将来的に多言語対応（英語・フランス語・中国語など）できるように、
i18n（国際化）の準備をしてください。
今は日本語のみで動作すればOKですが、
すべてのUIテキストを翻訳ファイルから読み込む構造にしてください。

## ライブラリ
react-i18next と i18next をインストールしてください。

npm install react-i18next i18next i18next-browser-languagedetector

## ファイル構成

src/
  i18n/
    index.js          ← i18nの初期設定
    locales/
      ja.json          ← 日本語（メイン）
      en.json          ← 英語（今は空でもOK、キーだけ同じにする）

## src/i18n/index.js の設定

import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import LanguageDetector from 'i18next-browser-languagedetector';
import ja from './locales/ja.json';
import en from './locales/en.json';

i18n
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    resources: {
      ja: { translation: ja },
      en: { translation: en },
    },
    fallbackLng: 'ja',
    interpolation: {
      escapeValue: false,
    },
  });

export default i18n;

## App.jsxのエントリポイントに追加

import './i18n';  ← ファイルの先頭付近に追加

## 重要なルール

1. 既存コード内の日本語文字列をすべて検索し、t() 関数に置き換える
2. 動的な値は interpolation を使う: t("home.currentAge", { age: "生後0ヶ月" })
3. 数値の単位も翻訳対象にする（"ml", "分", "円" など）
4. エラーメッセージもすべて翻訳ファイルに入れる
5. altテキストやplaceholderも忘れずに
```

```
## 書き換えのルール

各コンポーネントの先頭で useTranslation をインポート:

import { useTranslation } from 'react-i18next';

function MyComponent() {
  const { t } = useTranslation();
  
  return <h1>{t("home.cryingRescue")}</h1>;
}

## 書き換え例
```

## 将来の言語追加方法（メモ）

i18n導入後、新しい言語を追加する手順は以下の3ステップだけです：

1. `src/i18n/locales/fr.json` を作成（ja.json をコピーして翻訳）
2. `src/i18n/index.js` に `import fr from './locales/fr.json'` を追加
3. resources に `fr: { translation: fr }` を追加

これだけで、設定画面から言語を切り替えられるようになります。
