# 根拠検索の前に条件を確認する非公開試作

## 目的と公開範囲

相談者自身が対象者・子どもの年齢等を確認してから根拠資料を検索する試作です。
AI回答、診断、治療提案、架空の専門家返信は作りません。

「非公開」は、通常アプリのルーターやAPIに登録せず、新規の所有確認済み
一時環境のloopback内だけで動かす、という意味です。認証付き本番サービスの
完成を意味しません。通常アプリの起動・再起動や既存DBへの接続は行いません。

## 入力の扱い

- 相談対象：「子どもについて」「保護者自身について」「両方」「まだ分からない」。
- 子どもは個別に「子ども1」等として区別し、氏名は求めない。
  複数の子どもの年齢や健康条件を混ぜない。
- 歳・月は明示入力。空欄を0にせず、不明は未確認のまま検索できるようにする。
- 質問文中の年齢候補は確認の注意表示にだけ使用し、入力欄や検索条件を
  自動補完しない。複数の候補を各子どもへ自動割り当てしない。
- 質問と選択年齢が食い違う場合は、その違いを確認してもらう。
- 育児記録・家族情報・相談履歴・個人プロフィールは参照しない。
- 健康に関する追加確認は、その検索で関係する資料の適用条件にある場合だけ
  表示する。「該当する」「該当しない」「分からない」を区別し、
  未入力を「疾患なし」とみなさない。未確認のまま閲覧できる。
- E03の除外条件は子どもまたは保護者の診断に関係し、E04は子どもの診断に
  関係する。その違いを追加確認の文言に明示する。保護者のみ・対象未確認の
  検索では、保護者の状態を子どもの条件に代用せず、対象条件を未確認に維持する。
- 入力はその画面のメモリー内だけで扱い、ブラウザ保存領域・通常ログ・相談履歴
  へ保存しない。外部AIや外部検索サービスへ送らない。

## 状態表示

1. 入力した条件に適合する資料が見つかった。
2. 資料は見つかったが、適用条件に未確認事項がある。
3. 今回の収録資料では、指定条件に合う資料が見つからない。
4. 検索語に対応できず、資料の有無を判断できない。
5. 検索が未完了、または通信に失敗した。

「科学的根拠が存在しない」とは表示しない。一項目の適合だけで資料全体の
適用を確定しない。今回の4資料は日本への適用等に未確認事項があるため、
全体の適合確定を示すためにメタデータを書き換えてはいけない。

結果には原文、出典URL・版・箇所、条件と注意、関連する方法・限界等を分けて
表示する。英語原文を未確認の翻訳に置き換えない。

## 語句の対応と条件判定の分離

「発達障害」等の語句から関連資料の検索語を補う場合も、診断されたことや
研究結果を適用できることを意味しない。検索語の補足を知らせ、適用に必要な
事実は別に相談者が確認する。追加条件も子ども・対象者ごとに保持する。

今回の一時環境で試作画面が動いたことを、この問題の解消や公開許可と扱わないでください。

## 検証の起動と終了

    npm run test:evidence-prototype

この専用コマンドは、最小環境で安全性検査を行い、専用の一時確認サーバーを
起動・停止してから、試作画面用の別プロセスでブラウザ検証を行います。
従来の通常アプリ用ライフサイクル起動も使いません。
各実行は新規の所有確認済みPostgreSQLだけを使い、終了時に停止・削除します。
テストファイルや試作サーバーを直接実行してはいけません。

実装は `prototypes/evidence-consultation/`、画面例と検証記録は
`evidence-work/consultation-prototype/` にあります。通常のプレビューURLへ
追加した画面ではありません。確認後に試作サーバーを起動したまま残していません。
